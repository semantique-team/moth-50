# E-024 (P8) — ×3-term unpruned LM

**Pre-registered 2026-11-23, before the LM build or any readout.** The control
is the current product acoustic (E-023 R1 seed 0) with the E-034c LM.

## Question

Does the unpruned E-034 N2_1_1 LM built with A3's **×3 term weighting** improve
English-term accuracy (ETA) on the calibration set without a WER regression,
and survive the S1-dev veto and the dev-macro guard, at the same package
budget?

## Arm

The E-034c corpus (185,103 rows, sha256 `569c8233…`: frozen E-031 corpus minus
the 900 S1-dev sentences) with exactly one change:

| Parameter | E-034c (control) | E-024 (arm) |
|---|---:|---:|
| `term_weight` | 1 | **3** |
| `min_bigram` | 1 | 1 |
| `min_trigram` | 1 | 1 |
| `backoff` | 0.4 | 0.4 |
| tokenizer | `d6e1054e…` | same |
| order | trigram, N2_1_1 | same |

Term weighting duplicates the 134 term-bearing sentences in the count stream;
the n-gram **type** set is unchanged, so the binary should stay close in size.
The build is `tools/build_lm_from_corpus.py` (Moth E-031 builder); the packed
format is MOTHLMB2 at 10 bits, lossless (`tools/pack_lm.py`).

## Gate (fixed before the readout)

1. **Calibration win (R-S1-cal, primary).** ETA is better than the control with
   a paired 95 % CI excluding zero **and** WER is not worse (WER-difference CI
   not entirely above zero); **or** WER is better with a CI excluding zero
   **and** ETA is not worse (ETA CI not entirely below zero). Otherwise the arm
   is not adopted.
2. **S1-dev veto.** WER-difference CI is not entirely above zero and
   ETA-difference CI is not entirely below zero (E-002 §6.2), on R1 seed 0.
3. **dev-macro guard.** Macro-WER difference CI is not entirely above zero
   (no significant regression). Report the point estimate.
4. **Budget.** The packed LM is lossless and the full package (current graph,
   LM, 16 kHz VAD, metadata) is **≤ 50,000,000 B**. If it is over budget, the
   arm is recorded as over-budget; no post-hoc pruning or term-weight change.
5. **T-S3 report-only, only after 1–4 pass.** The S3 subset of T-600 is compared
   against the product hypotheses as a check against Moth D42 (S1-only term
   addenda regressed S3). It is not a gate and does not rank.

If 1–4 pass, the result is a **new dated LM decision candidate** (D30); it is
not a product change until the package and browser checks are run and the owner
adopts it. If any gate fails, E-034c stays the product LM.

## Build and readout

```bash
# 1. clean corpus (same 185,103 rows as E-034c)
uv run --frozen --project ../moth-stt --extra training -- \
  python tools/clean_lm_corpus.py \
  --corpus ../moth-stt/runs/E-031/frozen/lm-corpus.jsonl \
  --scripts ../moth-cs-dataset/text-2026-11-dev/R-S1.jsonl \
  --out /tmp/lm-corpus-nos1dev.jsonl \
  --report runs/E-024/lm-corpus-clean-report.json

# 2. ×3-term LM (one variable)
uv run --frozen --project ../moth-stt --extra training -- \
  python tools/build_lm_from_corpus.py --corpus /tmp/lm-corpus-nos1dev.jsonl \
  --out runs/E-024/lm_e034c_x3 --term-weight 3 \
  --report runs/E-024/lm-build.json

# 3. lossless pack and budget
uv run --frozen --project ../moth-stt --extra training -- \
  python tools/pack_lm.py --lm runs/E-024/lm_e034c_x3.bin \
  --out runs/E-024/lm_e034c_x3_mothlmb2.bin --bits 10 \
  --report runs/E-024/lm-pack.json

uv run --frozen --project ../moth-stt --extra training -- \

  --config training/configs/base6-long.toml \
  --reference-hyp runs/E-023/s1-cal-s0.hyp.jsonl \
  --out runs/E-024/s1-cal.json --hyp-out runs/E-024/s1-cal.hyp.jsonl
uv run --frozen --project ../moth-stt --extra training -- \
  python tools/frozen_readout.py --mode mixed --name s1-dev \
  --onnx runs/E-023/release-s0/model.int8.onnx \
  --lm runs/E-024/lm_e034c_x3.bin --allow-other-lm \
  --manifest ../moth-cs-dataset/manifests/R-S1-dev.jsonl --shards data/shards/s1-dev \
  --config training/configs/base6-long.toml \
  --reference-hyp runs/E-023/s1-dev-s0.hyp.jsonl \
  --out runs/E-024/s1-dev.json --hyp-out runs/E-024/s1-dev.hyp.jsonl
# dev-macro guard
uv run --frozen --project ../moth-stt --extra training -- \
  python tools/frozen_readout.py --mode macro \
```

Artifacts go to `runs/E-024/`; checkpoints are not involved. No training.

## Result (2026-11-23) — not adopted

- **Build:** same corpus (185,103 rows, `569c8233…`), `term_weight = 3`,
  134 term sentences. MOTHLMB1 12,303,348 B (`0e7f0cbf…`, same size as
  E-034c); packed MOTHLMB2 7,787,184 B (`7c92ddaa…`, lossless). The LM differs:
  21,820 bigram and 69,673 trigram log-probs change.
- **R-S1-cal:** **12.8469 / 75.4967**, exactly the control; 0.0 pp WER and
  ETA, CI [0, 0], hypotheses byte-identical. **Gate 1 fails: no calibration
  win.**
- **S1-dev (veto):** 13.3966 / 75.0977 vs 13.3820 / 75.1465; WER +0.0146 pp
  [0, +0.0456], ETA −0.0488 pp [−0.1566, 0], both ties. Only 4/960 hypotheses
  change, all one-word term variants. Moot because gate 1 failed.
- **Not run:** dev-macro guard and T-S3 (gate 1 failed); no package/browser/T
  read.
- **Verdict:** **E-034c stays the product LM.** ×3 term weighting is not a
  lever at the frozen decoder on this graph; record the negative result and
  move to E-018. `runs/E-024/RESULT.md`.
