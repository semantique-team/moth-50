# MOTH-50 0.9.8-e023-r1

Released **2026-11-26**. This is the final release of the MOTH-50 line.

## What it is

An Italian + English code-switching speech recognizer: a pretrained Whisper-base
encoder (MIT), six additional pre-LN transformer blocks and a linear CTC head
over a shared IT+EN SentencePiece BPE. It is encoder-only and
record-then-transcribe, not streaming and not an LLM-decoder system. The full
runtime package is **49,204,097 bytes** and runs on CPU and in the browser
through ONNX Runtime Web/WASM.

`0.9.8-e023-r1` is a **NOTICE-only repackaging** of `0.9.7-e023-r1` (D37). The
graph, LM, VAD, vocabulary and mel filters are byte-identical. The corrected
NOTICE describes the shipped LM as MOTH-50's E-034c rebuild, with both the
shipped sha256 `7a4332f1…` and the source sha256 `4b122fbe…`, instead of calling
it Moth 0.8.1's file "reused unchanged".

## Browser

The release transcript is exact on the smoke clip at **RTFx 28.48** (5-run
median, 4 threads, isolated, SIMD, load 79.7 ms). The public static demo serves
the same bytes without COOP/COEP, so it runs 1-thread WASM and measures about
**10× realtime** on a 4 s clip.

## Reproducibility

The repository retains the experiment ledger, per-utterance hypotheses, metrics,
comparison JSON and release records. Checkpoints, raw audio, mel shards and the
release binaries are not versioned; a clean clone can re-score the readouts but
cannot retrain the model. The release package is rebuilt with
`tools/export_release.py` and repackaged with `tools/renotice_release.py`; the
Hugging Face upload and the Space are guarded by `tools/upload_hf.py` and
`tools/publish_space.py`.
